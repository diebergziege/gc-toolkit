Alte Fassung wird noch angezeigt?
Zuerst prüfen, ob der Server überhaupt läuft. Lädt die Seite sehr lange, ist das fast immer die Ursache – nicht der Cache. Er läuft in der gctk UI (Demos → Vendor Battle) und endet, wenn die gctk UI beendet wird.
HTML kommt mit no-store, Assets mit no-cache – der Browser fragt kurz nach und bekommt ein leeres 304. Änderungen sind sofort da, ohne dass etwas neu geladen wird.
Bleibt doch einmal eine alte Fassung stehen: /now/ vor den Dateinamen setzen – das erzeugt bei jedem Aufruf eine URL, die es vorher nie gab.
http://localhost:8090/now/cockpit.html
